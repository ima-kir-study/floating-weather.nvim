1. INTRODUCTION					*floating_weather-intro*

Floating Weather shows current weather in floating window in Neovim. The data
is taken from wttr.in

Features:
    • description, temperature, feels like, wind, pressure, UV-index
    • transparent background

==============================================================================
2. PLATFORMS					*floating_weather-platforms*

• Tested on Linux. Plugin work on other platforms is not guaranteed.

==============================================================================
3. REQUIREMENTS					*floating_weather-requirements*

• nvim (tested on v0.12.5)
• curl

==============================================================================
4. INSTALLING					*floating_weather-installing*

Packer: >

    use {"ima-kir-study/floating-weather.nvim"}

<

==============================================================================
5. SETTING UP					*floating_weather-setting-up*

Add to your init.lua smth like this: >

vim.keymap.set(
    "n",
    "<leader>w",
    ":ToggleFloatingWeather<CR>",
    { desc = "FloatingWeather plugin!", buffer = true, silent = true },
)

require("floating_weather").setup({
    city = 'Москва',
    transparent_bg = true,
})

<

==============================================================================
6. COMMANDS					*floating_weather-commands*

:ToggleFloatingWeather      *:ToggleFloatingWeather*
    Open floating window with weather.

==============================================================================
7. MAPPINGS					*floating_weather-mappings*

Inside the floating window:
    q    Close window.

==============================================================================
8. USING					*floating_weather-using*

If you use settings from the |floating_weather-setting-up| section, press
<leader>w
